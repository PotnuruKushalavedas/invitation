# 💍 Engagement Invitation Website

### A Custom Digital Engagement Invitation

> A responsive and interactive engagement website developed as a **commission project**, transforming a traditional invitation into a personalized digital experience.

## 🌸 About

This website provides guests with all important engagement details in one place, including:

* 💍 Couple information
* 📅 Event date & schedule
* 📍 Venue & location
* 📸 Photo gallery
* 💌 Personalized invitation content

## 🎯 Uses

* Digital engagement invitations
* Easy sharing through a single link
* Mobile-friendly access for guests

* Creating a personalized digital experience
